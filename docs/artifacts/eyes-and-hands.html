Eyes and Hands

Computer Use means the coworker takes a photograph of a screen and then clicks on it. Which screen, whose mouse, and what happens when a password box appears — the three questions everybody gets wrong.

What it is

Look, decide, act — and then look again

There is no magic and no special channel. Every step is an ordinary tool call, which is why everything else in the building applies to it unchanged.

Which screen

A screen with no monitor attached to it

The desk has a display that exists purely in memory. Nobody is looking at it. Windows open on it, a browser draws into it, and screenshots are taken from it — all with no physical screen anywhere in the story.

The confusion

Three things people mean by “the bot used my computer”

Only one of them is Computer Use, and it is the one that never touches your machine.

Coordinates

The picture and the click must agree

The one genuinely fiddly part. The model sees an image and says “click at 412, 288”. If the image it saw is not the same size as the screen being clicked, every click lands somewhere slightly wrong — and it looks like the model is bad at clicking.

The rule

When a password box appears, stop

A coworker driving a browser will eventually hit a login form. Typing a password there means the password went through the model, into the transcript, and possibly into a screenshot. So the rule is: do not.

The judgement

Reach for this last, not first

Computer Use is slow, expensive and fragile compared to every alternative. It is also the only thing that works when there is no alternative. Both facts matter.

If the service has…UseWhy
A connector (MCP server)The connectorStructured, fast, one call, and the result is data rather than a picture of data.
An API but no connectorA shell tool on the deskStill structured. Cheaper than looking at a screen to read a number.
Only a websiteThe browser, driven by computer useNow it is the right tool. This is what it is for.
A desktop app with no other surfaceComputer useSame reason.
A login step in any of the aboveA human, once, via handoffThen the cookie carries it.

The cost, concretely. One screenshot is a large image in the model’s context, and a task might need dozens. A connector call that returns twenty rows of text costs a fraction of one screenshot. If a coworker is reading numbers off a screen that an API would hand over directly, that is a missing connector, not a clever use of computer use.

The invariants

What Computer Use never does

  • Touch the screen you are looking at. It has no route to your machine.
  • Get a private channel. Every action is an ordinary, governed tool call.
  • Skip auto-review. Every click is judged like every other tool call.
  • Type a password the model was given. Passwords come from a human, on the desk.
  • Clamp an out-of-range click. It refuses, so the mistake is visible.
  • Assume an action worked. It looks again.
  • Require a human to be watching. Watching is optional and always available.
  • Be the first choice when a real API exists.

One sentence

A photograph of a screen nobody is looking at, a click sent back to the same pixels — and a human for the one box that should never reach a model.
