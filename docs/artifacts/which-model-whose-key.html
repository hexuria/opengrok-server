OpenGrok · picture book · hard topic 6

Which Model, Whose Key

Every model call in the building leaves through one door. That door picks the model, picks which of your credentials to spend, speaks whatever dialect the provider wants, and writes down what it cost — including what it would have cost if you had not been careful.

The path

Six things happen to every call

Two of them save you money, two of them keep the call alive when something breaks, and two of them are bookkeeping. None of them are optional.

Which model

A coworker names a route, not a model

If every coworker named a specific model, every model change would be an edit to every coworker. Instead a pin is a name the door resolves — and three of those names deliberately refuse to be specific.

When it breaks

Two kinds of failure, and mixing them up wastes money or breaks the run

A failed call is not just “a failed call”. There are two species with opposite correct responses, and one pure decision decides which you are looking at.

The counterfactual

The number that makes the saving real

Anyone can claim their routing saves money. The claim is only checkable if, on every single call, you also record what that exact call would have cost at the top rung. So the door does.

The two doors

The same floor answers your coworkers and your developers

The building’s own coworkers call this floor in-process. Outside tools — a coding agent on a laptop, a script, an SDK — reach the same machinery through the model door. One set of credentials, one meter, one budget.

The invariants

What the door never does

  • Execute a tool. It returns a request to; something else decides and does.
  • Manage a container, a desk, or a volume. It has never heard of them.
  • Let a credential reach a coworker’s record, a window, or a log.
  • Let a model pin be a key. A pin is a name it resolves at call time.
  • Escalate because a key was rate limited, or fail over because a model was too small.
  • Report a saving it cannot show you the two columns for.
  • Charge a subscription seat as free. The list price it displaced is the honest figure.
  • Decide what happens when a budget is crossed. It measures; Policy judges.

One sentence

One door for every model call, so the decision is made once, centrally, and the saving is a column you can add up rather than a claim.
