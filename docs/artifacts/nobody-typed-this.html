OpenGrok · picture book · hard topic 7

Nobody Typed This

A coworker that only answers when spoken to is a chatbot. Three mechanisms let a run start with no person present — and one shared trick stops all three from firing twice or chasing their own tails.

The three

The clock, the ear, and the megaphone

They differ only in what wakes them. All three end the same way: by asking for a run, exactly as a person would. None of them runs a turn itself.

The shared trick

Two servers, one due schedule, one run

The building runs on more than one machine. All of them see the same clock and the same events. Without care, a schedule due at 08:00 fires once per machine — and the coworker sends three copies of the same email.

The trap

A monitor that watches its own runs will never stop

Monitors listen to events. Runs produce events. If a monitor listens for something its own run causes, it fires itself forever — quietly, expensively, at machine speed.

The megaphone

“Tell everyone” is written once, then fanned out

The tempting implementation loops over coworkers and sends to each. It half-fails: some get it, some do not, and nothing knows which. Writing the instruction down first turns delivery into something that can be retried.

Why they run as their owner. An autonomous run with no principal would have no grants, no budget and nobody to raise a card to. Running as the owner means an unattended run can still suspend and wait — the owner answers whenever they next look.

The invariants

What autonomy never does

  • Run a turn itself. It asks for one, like a person would.
  • Bypass policy, cards, or budgets because no human is watching.
  • Fire twice for one occurrence, on any number of replicas.
  • React to an event its own run produced.
  • Run as nobody. Every autonomous run has an owner and a principal.
  • Deliver to many by looping and hoping.
  • Need a leader, a coordinator, or a separate scheduler service.
  • Keep firing after the coworker is gone.

One sentence

Three ways to ask, one way to run — so a coworker working at 3am is governed exactly like one working while you watch.
