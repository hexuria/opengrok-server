The Desk and the Door

They look like rivals because both are URLs your config points at. They are one employee and one switchboard — and the employee calls through the switchboard.

The desk · a coworker’s body

localhost:4201/ag-ui

speaks AG-UI — the conversation wire
  • Receives a turn: the messages, the tools it may use, its standing role.
  • Runs the loop: think → call a tool → read the result → answer.
  • Streams the answer back as events your channel renders live.
  • Every tool call goes back through OpenSesame — grant, policy, audit.

Holds a runtime token so OpenSesame trusts it. Never a model key.

The door · the model switchboard

127.0.0.1:29080

speaks OpenAI dialect — the model wire
  • Holds every credential: your Grok seat, any pooled API keys.
  • Resolves a route — xai/grok-4.6@sub, oag/auto — to a live credential.
  • Meters spend, enforces budgets and reserves, keeps the ledger.
  • Refuses with a reason when nothing can serve.

Answers one question only: “complete this prompt.” It has no loop, no tools, no memory.

Your questions, straight

Conflicting? Pick one? Merge them?

Do they conflict?

No — they never answer the same question. The desk answers “do this work.” The door answers “think this thought.” Different wires, different jobs, one calls the other.

Should we use both?

You already do, on every turn. The Grok answer above passed through both addresses — desk first, door second. Remove either and the turn dies: no desk, nobody works; no door, nobody thinks.

Why not just the desk, with the gateway built inside it?

Because then every coworker becomes a keyholder — which is the exact bug this product was rebuilt to escape.

The merge, played forward

Fold the gateway into the agent and each agent process now carries credentials:

agent #1 · grok seat agent #2 · grok seat agent #3 · grok seat rotate = touch every one

One roof for spend and budgets becomes N copies that disagree. A third-party coworker on someone else’s server would need your key shipped to them. And a bug in any agent’s loop sits in the same process as the wallet.

Kept apart: a coworker names a route, never holds a key; rotate once at the door; every token of spend lands in one ledger. The desk can crash, be rewritten, or live on a stranger’s machine — the wallet never moves.
